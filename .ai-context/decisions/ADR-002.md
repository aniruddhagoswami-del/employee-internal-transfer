# ADR-002: Optimistic Concurrency Control via Entity Versioning

## Status
Approved

## Date
2026-09-04

## Context
High potential for race conditions exists if an employee attempts to withdraw an application simultaneously with a manager or HR partner executing an approval action.

## Decision
Enforce **Optimistic Concurrency Control (OCC)** using an integer `version` field incremented on every state transition and entity mutation.

## Consequences
- **Positive:** Eliminates dirty writes and phantom updates without database-level row locking; scalable across distributed instances.
- **Negative / Risks:** Concurrent conflicting requests receive HTTP 409 Conflict and must refresh their client state before retrying.
