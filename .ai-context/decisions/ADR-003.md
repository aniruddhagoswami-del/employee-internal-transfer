# ADR-003: SHA-256 Hash-Chained Append-Only Audit Ledger

## Status
Approved

## Date
2026-09-04

## Context
Internal talent mobility, role changes, and cross-cost-center transfers require strict regulatory, HR governance, and SOC2 audit compliance. Audit records must be mathematically provable against unauthorized mutation.

## Decision
Implement a cryptographic blockchain-style **SHA-256 Hash Chain** on the audit log table, linking each record to the previous record's hash (`prevHash`, `currentHash`).

## Consequences
- **Positive:** Unambiguous mathematical tamper-evidence; any post-hoc database mutation immediately breaks the chain and is detected during automated verification runs.
- **Negative / Risks:** Requires linear serialization when calculating next hashes.
