# ADR-005: Multi-Tenant Role & Object-Level Access Control (OLAC)

## Status
Approved

## Date
2026-09-04

## Context
Preventing Broken Object-Level Authorization (OWASP API1:2023 / BOLA / IDOR) is critical so that employee A cannot view or manipulate employee B's sensitive transfer dossier, and unauthorized managers cannot view peer employee transfers.

## Decision
Implement fine-grained authentication middleware that validates both Role-Based Access Control (RBAC) and Object-Level Access Control (OLAC) on every `/transfers/:id` entity endpoint.

## Consequences
- **Positive:** Complete protection against IDOR / BOLA attacks; strictly isolates access to the transferring employee, current manager, receiving manager, and authorized HR partners.
- **Negative / Risks:** Requires database / state lookup in authorization middleware prior to route handler execution.
